OVERTHINKERS PARADISE — PREMIUM STARTER

Files: index.html (content), style.css (design), script.js (demo interactions).
This is a front-end demo. Posts are stored only in the current browser. Sign in is a placeholder; real accounts, shared posts, DMs and file uploads are not connected yet.

HOW TO UPDATE GITHUB:
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Click Add file > Upload files.
4. Upload index.html, style.css and script.js from the extracted folder (not the ZIP).
5. Commit changes and confirm replacing existing files if asked.
6. Wait a few minutes, then refresh your GitHub Pages website.
